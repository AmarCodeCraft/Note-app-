# Note App using Express and Ejs

A simple note app built using Express as the backend and Ejs as the templating engine.

You can see my website here: https://note-app-ejs.up.railway.app

### Features

- Create a note
- Read a note
- Delete a note

### Installation

1. Clone the repository
2. Navigate into the project directory
3. Install the dependencies using npm by running `npm install`
4. Run the app using `npm start`

### Usage

1. Open a web browser and navigate to `http://localhost:3000`
2. Click on the "Create Note" button to create a new note
3. Fill in the title and details of the note and click on the "Create Note" button
4. Click on the "Read Note" button to read the note
5. Click on the "Delete Note" button to delete the note
